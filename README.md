# Patient Appointment & Reminder Automation

## Dental Clinic Automation System

A comprehensive appointment management and reminder automation system for dental clinics, integrating UiPath RPA, Twilio communications, and Google Sheets.

### Features
- 📅 Appointment scheduling with conflict detection
- 📱 SMS/WhatsApp/Email reminders via Twilio
- 🤖 UiPath RPA integration for automation
- 📊 Analytics dashboard with no-show tracking
- 🌐 Multi-language support (EN/AR)
- 🧠 ML-based no-show prediction

### Tech Stack
- **Frontend**: Next.js 14, React 18, Recharts
- **Backend**: Express.js, Node.js
- **RPA**: UiPath Studio
- **APIs**: Twilio, Google Sheets, Google Calendar
- **ML**: Python, scikit-learn

### Getting Started

```bash
npm install
npm run dev:all
```

Open [http://localhost:3000](http://localhost:3000) for the dashboard.
API runs on [http://localhost:3001](http://localhost:3001).
